# Security Policy

## Supported Versions

| Version | Supported          |
| :---    | :---:              |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **Interframe**, please do **not** open a public issue.

Instead, please send an email to:
- **Adityajyoti Kar**: [kar323834@gmail.com](mailto:kar323834@gmail.com)

Please include:
1. Description of the vulnerability.
2. Steps or scripts to reproduce the issue.
3. Affected versions or environments.

We will acknowledge receipt within 48 hours and coordinate a timely fix and advisory.
